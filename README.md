# connectN
This project is a console-based implementation of the Connect-N game (a generalization of Connect 4) written in C++ with no GUI integration.
Players take turns dropping pieces into columns of a customizable grid, trying to connect a sequence of N identical symbols horizontally, vertically, or diagonally.

The program includes advanced features such as:

A menu system with multiple options

Save and load functionality

Customizable board size and win condition (N)

Automatic state saving after every move

Resume previous game or start a new one
